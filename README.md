# LMS Project

Система управления обучением (LMS) с Django REST Framework.

## Функциональность

- JWT аутентификация
- CRUD операции для курсов и уроков
- Подписки на курсы
- Права доступа (модераторы, владельцы)
- Валидация YouTube ссылок
- Пагинация
- Платежи
- Тестовое покрытие
